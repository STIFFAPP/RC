INSTALL
1. Upload all files to GitHub Pages, Cloudflare Pages, Netlify, or another HTTPS static host.
2. Open the live site in Safari on iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Launch Recovery Quest from the new icon.

IMPORTANT
Export a backup before clearing Safari website data or changing devices.
